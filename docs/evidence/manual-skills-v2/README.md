# Companion skills v2

New expeditions begin with each family's distinct signature cooldown and behavioral passive, supplemented by a distinct two-stat family talent. Additional cooldown slots unlock at levels **3, 5 and 7**, for a maximum of **four cooldown skills plus the basic attack**. Ordinary levels add stats without skill prompts.

Each unlocked slot offers three saved, manually selected cooldowns. Offers favor the companion's role and element and use rarity-weighted Basic, Refined, Superior and Mythic quality. Higher quality improves real potency and base cooldown. Repeated selections cannot grant duplicate skills.

Evolution activates its family/path passive and offers two exclusive cooldown choices. It fills an available unlocked slot or requires an explicit replacement of a non-signature cooldown. Skills exceeding the new limits during migration, and deliberately replaced skills, are preserved in skill history. Existing saves retain their valid active choices without replaying old level-up prompts. Enemies use the same level slot limits with deterministic skill selection; captures retain their skills.

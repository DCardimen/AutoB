# Iteration 1 — Training Glade · Native Pixel v6

The movement prototype now has nine character types rendered as original **64×64 pixel sprites**, with shorter limbs, eight facings, a five-hero four-direction showcase and separate animation examples. It uses Canvas 2D and a crisp shared world grid. The hound stays four-legged; a fox ranger, six-legged brass walker, eight-legged spider and moon jelly expand the representative roster.

Running and sprinting have distance-driven gaits and real acceleration. Cape springs, turn poses, fast braking, physical dodges, constrained death ragdolls, heavy-hit knockdowns and get-up transitions are implemented. Shared anatomical and weapon poses retain contact alignment. The Godot export provides **8,640 cells and 120 animations per actor**, with a working Godot 4 demonstration project.

In GitHub Desktop, use `codex/starfall-menagerie`, **Fetch origin → Pull origin**, then reopen or refresh **Starfall-Training-Glade.html**. Verify **NATIVE PIXEL V6** in the header. Playing needs no installation or WebGL. Keep `Starfall-Menagerie.html` alongside it for the Expedition link.
